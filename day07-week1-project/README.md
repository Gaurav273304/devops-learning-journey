## The Project: Server Health Monitor
A bash script that checks disk usage, free memory, and whether a specific process is running — then logs everything with a timestamp and raises a warning if disk usage crosses a threshold.

### Key techniques used
```bash
# Extracting a clean number from command output using a pipeline
disk_usage=$(df -h / | grep / | awk '{print $5}' | sed 's/%//')

# Checking if a process is running (excluding the grep command itself)
if ps aux | grep -v grep | grep "bash" > /dev/null
then
    echo "Process running"
fi
```

**Concepts combined:** variables, conditionals, `df`/`free`/`ps`, pipelines (`|`), `grep`/`awk`/`sed`, output redirection (`>>`, `/dev/null`), file permissions (`chmod +x`), and a full Git branching workflow.
